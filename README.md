# Implementation-and-Analysis-of-Intrusion-Detection-System-Suricata-IDS-
Configured a GNS3 simulation integrating Suricata IDS (Ubuntu) for real-time traffic analysis. Simulated various attacks (DoS/DDoS, SNMP Reconnaissance, Nmap Scan, Telnet Brute Force) using Kali Linux. Analyzed Suricata's alerts, logs, triggered detection rules, and evaluated system performance impact.
